# Заимствования

Quillwright распространяется по лицензии Apache License 2.0.

**Кода, взятого из других проектов, здесь нет.** Всё написано по нормативным текстам: где
спецификация печатает таблицу значений, таблица транскрибирована, но ни одна реализация не
портирована и не скопирована. Поэтому файла `NOTICE` у пакетов нет — пункт 4(d) Apache-2.0
требует его только для производной работы, а такой здесь не возникает.

Ниже перечислено, по каким нормативам сделано то, что могло бы выглядеть как заимствование.

Open Specification Promise; сами тексты сюда не включены, только ссылки на них в комментариях.

## Чего здесь нет намеренно

- **Таблиц переносов.** `Quillwright.Pdf` реализует алгоритм Лианга, но не везёт с собой ни
  одного файла шаблонов: `hyphen.tex` из TeX и словари `hyph-*.dic` из LibreOffice и Hunspell
  идут под лицензиями своих проектов, поэтому какой файл загрузить — решение вызывающего
  (`HyphenationPatterns.Parse`).
- **Документов для тестов.** Корпус реальных файлов Word, на котором проверяется чтение и
  round-trip, принадлежит другим проектам и в репозиторий не входит; тесты, которым он нужен,
  пропускаются. Откуда его взять, написано в [docs/testing.md](docs/testing.md).
- **Шрифтов.** Метрики берутся из шрифтов, установленных на машине; ни один шрифт не встроен.
